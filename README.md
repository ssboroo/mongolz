# MONGOLZ Casino Demo

Premium Mongolian / English casino UI demo with 8 playable browser games and a local demo wallet.

## Included
- MN / EN language switch
- Premium MONGOLZ dark / gold / sky-blue responsive UI
- Demo balance saved in `localStorage`
- Session history
- Working demo games: Slot, Roulette, Blackjack, Baccarat, Plinko, Mines, Dice, Crash
- Demo cashier UI for Visa, Mastercard, USDT, USDC, BTC and ETH
- **No real-money transactions**

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy
Works as a standard Next.js application on Vercel or Railway.

## Important
The included random engines are for UI/demo purposes only. They use `Math.random()` and are not certified or suitable for real-money gambling.
